# 岗位图自监督原型：九组实际训练与负结果

执行日期：2026-09-22。结论：**图编码与训练链可以运行，但本轮没有证据证明真实需求图优于随机边或简单池化。模型不晋升线上人岗排序器。**

## 实际数据与执行

输入是仓库外规范化研究数据的14,118个岗位内容版本；沿用旧业务键的三个冲突版本分别保留，没有误复用旧岗位向量。训练9,898条、开发2,108条、测试2,112条；按13,944个岗位家族划分。93个技能、57,192条投影软消息边中，mentioned为51,339、preferred为2,175、alternative为3,678；现规则未提供明确required优先级，因此没有伪造必需边。

特征为根代理重新逐内容版本编码的BGE-small-zh-v1.5，512维、CLS与L2归一化，revision为`7999e1d3359715c523056ef9478215996d62a620`。输入快照、逐岗位snapshot、jobs文件SHA-256和特征manifest均已校验。

固定实验计划为GraphSAGE、pool-MLP、随机边GraphSAGE各跑42/43/44三个种子。每组均完成5个完整epoch，每轮39步、9,898个训练锚点，没有截断训练步数。按开发集loss选择检查点，九组均选中第5轮；测试指标只在该组检查点选定后计算，没有根据测试结果调整配置。开发与测试评估全部查询，训练评估取固定随机子集3,000条。

默认参数：128维、两层关系均值传播、dropout 0.2、文本残差融合系数0.3、AdamW学习率0.001、weight decay 0.0001、batch 256、温度0.05。训练由单独进程在GPU2执行；未占用GPU0/1。每组记录的内部耗时约7.75–12.50秒，合计90.65秒，不含各进程导入等全部外部开销。峰值PyTorch已分配显存最高576.7MiB，是训练进程自身统计，不代表整卡总占用。

## 指标的确切含义

这些指标衡量“从某个岗位的图表示中找回该岗位的冻结文本向量”，候选库为同一评估分区的岗位。测试分母是2,112个查询和2,112个候选，同家族的其他岗位被屏蔽为未计负例。**这不是简历查询，没有人工相关性标签，不能称为职位推荐Recall、nDCG或录用效果。**

图输入和残差已经包含完整岗位文本，网络可能通过文本投影、自环和残差完成对齐；本轮不声称进行了严格遮蔽技能预训练。OR组只投影为alternative软消息边，未实现组节点传播或布尔满足逻辑，也未训练简历查询塔。

## 验证与下一步决策

八项CPU测试全部通过：保留集文本不改变训练岗位和共享技能状态；训练loss不经过保留文本反传；家族负例屏蔽；随机边度数与分区独立性；缺边纯文本回退；跨分区家族拒绝；快照与三方文件摘要校验；三个模式真实CPU训练与产物。
