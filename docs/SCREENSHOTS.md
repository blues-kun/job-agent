## 本次浏览器验收

验收流程：载入需求→进入匹配→选择内置样例→预览并确认画像→推荐→打开证据→三组算法比较→读取研究进度→移动端概览。

- 未出现 JavaScript 页面异常。
- 修复简历表单输入框撑开网格列的问题，采集脚本检查输入框不超过所属列。
- 修复手机导航和品牌挤压换行，390 像素视口无整页横向溢出。
- 反馈使用独立浏览器会话，采集后清理该会话反馈；没有提交人工标签或保存真实简历。

发布前 CPU 回归共 183 项通过，包含 3 项演示数据生成与路径保护用例。独立演示服务加载 16 个岗位，使用 BM25＋字符 TF-IDF，可在 CPU 上运行。CI 安装平台与树排序测试依赖后执行回归。

这是一条代表性流程与单个移动宽度的浏览器验收，不等于全浏览器兼容性、无障碍审计或独立推荐效果验证。

## 复采截图

先按 [仓库首页](../README.md) 启动本机平台，再在独立环境安装可选依赖：

```bash
python -m pip install -r requirements-screenshots.txt
python -m playwright install chromium --only-shell
python -m scripts.capture_screenshots --url http://127.0.0.1:8094 --output /绝对路径/截图目录
```

脚本使用本机 URL 和内置简历样例，遮罩公司名称；原始采集方式为 Playwright 页面交互与截图，采集环境保存在清单中。脚本会覆盖指定目录内同名截图，复采建议使用新目录。

演示材料说明：内置简历和 `scripts/create_demo_data.py` 生成的 **16 条岗位**均为预设的合成样例，用于功能验证。上述界面中的岗位统计来自另行配置的历史快照，企业名称已遮罩。研究指标的复现需要匹配的原表、数据划分与模型版本，配置方式见 [运行手册](V2_RUNBOOK.md)。
