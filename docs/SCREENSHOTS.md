## 本次浏览器验收

实际执行：载入需求→进入匹配→选择虚构简历→预览画像→主动确认虚构画像→推荐→打开证据→三组算法比较→读取研究进度→移动端概览。

- 未出现 JavaScript 页面异常。
- 修复简历表单输入框撑开网格列的问题，采集脚本检查输入框不超过所属列。
- 修复手机导航和品牌挤压换行，390 像素视口无整页横向溢出。
- 反馈使用独立浏览器会话，采集后清理该会话反馈；没有提交人工标签或保存真实简历。

发布前CPU回归共183项通过（包含新增的3项虚构数据生成/路径保护用例）；独立启动的演示服务健康检查返回16个岗位，明确使用BM25＋字符TF-IDF，无需GPU或接口。CI同步安装平台与树排序测试依赖，不读取私有原表。

这是一条代表性流程与单个移动宽度的浏览器验收，不等于全浏览器兼容性、无障碍审计或独立推荐效果验证。

## 复采截图

先按 [仓库首页](../README.md) 启动本机平台，再在独立环境安装可选依赖：

```bash
python -m pip install -r requirements-screenshots.txt
python -m playwright install chromium --only-shell
python -m scripts.capture_screenshots --url http://127.0.0.1:8094 --output /绝对路径/截图目录
```

脚本只允许本机 URL，使用内置虚构简历，遮罩公司名称，不自动领取或提交标注任务。它会覆盖指定目录内同名截图，因此复采建议使用新目录。

公开演示用 `scripts/create_demo_data.py` 生成 **16 条手写虚构岗位**，输出在仓库外。虚构岗位可验证功能流程，不用于复现 14,118 条真实历史快照的统计或训练指标。平台源码、固定种子、数据来源摘要与聚合结果可以公开，受限制原表与训练材料仍需由有权使用的数据持有者自行配置。
