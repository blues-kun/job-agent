基座为官方 `Qwen/Qwen3-Embedding-0.6B`，固定 revision `97b0c614be4d77ee51c0cef4e5f07c00f9eb65b3`。查询加入任务指令，使用最后有效 token 池化和 L2 归一化；文档移除重复标题文本。

`run_analysis.json` 含 2,000 次成对查询 bootstrap 的区间；这些区间只刻画当前查询样本的不确定性，不覆盖训练随机性、代理标签噪声或真实简历泛化。只有一个随机种子，本轮没有进行多种子验证。

输入截断方面，本次 4,800 个训练文档中 433 个超过 512 tokens（9.02%），开发文档中 181/2,107 超限（8.59%）。后续应在预先制定的方案下比较分块与更长序列，并在人工标注的简历—岗位留出集上验证。
