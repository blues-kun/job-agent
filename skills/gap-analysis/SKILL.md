# 岗位差距分析

输入简历版本、岗位ID及同一数据快照。逐项检查硬条件，区分满足、冲突、未知；优先条件不当硬门槛。岗位出现“任一种”时按替代组处理，不能把组内未掌握的另一技能报成必需缺口。

匹配项提供岗位和简历双侧引用。未写明技能只能说“简历未提供证据”，不能断言用户不会。历史薪资只比较同职类、同年资的广告月薪中点，样本不足30不报分位。

输出匹配项、待补证项、硬冲突和可核验的下一步。本地执行器为 `Workflow.diagnose`。
