# 事实保全改写

输入简历原文、岗位ID与差距分析。当前确定性模式保留完整段落，只有不存在指代或顺序关系时才将相关段落前置；保留前后版本与可审查的改动。不拆开“项目甲……后者……”等依赖关系。

不得补造公司、项目、数字、工作年限，也不得把“了解”升级为“精通”。缺少的能力作为待用户补证或学习建议，不插入简历。逐句多重集合与技能级别一致后才能返回整理稿，失败保留原文。

返回原文、整理稿、事实保全检查、待补证建议。用户审核应用后才能以新版本重新匹配。执行器为 `Workflow.rewrite`。
